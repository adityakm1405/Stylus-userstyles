## `01` — The philosophy

> The web doesn't have to look the way it was shipped.

**Stylus Userstyles** is my personal collection of custom website themes created with CSS and the [Stylus browser extension](https://github.com/openstyles/stylus).

From immersive dark interfaces to cleaner layouts and carefully tuned color palettes, each style aims to give a website its own visual identity without rebuilding the website itself.

<div align="center">

| `◈` Visual identity | `⌘` CSS-powered | `✳` Community-friendly |
|:---:|:---:|:---:|
| Distinct palettes and design language | Custom styling without replacing the website | Explore, adapt, and improve the code |

</div>

## `03` — Install a style

<div align="center">

**Your browser. Your rules. Your aesthetic.**

Install a theme in a few clicks, directly from GitHub or through my style profiles.

</div>

### The recommended way — Stylus

<details open>
<summary><strong>Show installation instructions</strong></summary>

**01 · Install Stylus**

Get the Stylus browser extension for your browser:

<a href="https://add0n.com/stylus.html"><img src="https://img.shields.io/badge/GET_STYLUS-Browser_Extension-164D36?style=for-the-badge&logo=firefoxbrowser&logoColor=white" alt="Get Stylus"/></a>

**02 · Choose a theme**

[Open the repository](https://github.com/adityakm1405/Stylus-userstyles/tree/main) and navigate to the theme you want to install. Open its `.user.css` file by clicking its filename.

**03 · Click the Raw button**

Once the file is open on GitHub, look at the **top-right corner of the code panel**. You'll find a button labelled **Raw**.

Click **Raw** to open the actual stylesheet instead of GitHub's formatted code view.

> **Can't find the Raw button?** Make sure you've opened an individual `.user.css` file, not just the repository homepage or a folder. The button appears in the top-right area of the file view.

**04 · Install through Stylus**

With Stylus installed and enabled, opening the raw `.user.css` URL in your browser should trigger Stylus's UserCSS installation page.

Review the theme details and click the installation option provided by Stylus to add the style to your browser.

**05 · Enable and enjoy**

Visit the website the theme was designed for and make sure the style is enabled in Stylus.

If the installation prompt doesn't appear, check that Stylus is installed and enabled in the **same browser** where you're opening the raw URL. Also verify that you're opening the raw file URL rather than the regular GitHub file page.

</details>

## `04` — The design language

<div align="center">

| Element | Approach |
|:---|:---|
| **Color** | Intentional palettes, balanced contrast, restrained accents |
| **Surfaces** | Layered backgrounds that establish visual hierarchy |
| **Interaction** | Thoughtful hover states and visual feedback |
| **Layout** | Website-specific spacing, alignment, and component styling |
| **Maintainability** | Readable CSS and reusable design tokens where practical |

</div>

These are design goals, not a promise that every style uses the same palette or implements every feature. Each redesign is tailored to its target website.

## `05` — Make it yours

Found something you want to tweak? Go ahead.

You can use these styles as a starting point for your own browser customization projects.

- **Explore** the selectors and understand how the original website is structured.
- **Customize** colors, spacing, typography, and other visual properties.
- **Experiment** with your own design ideas.
- **Contribute** fixes or improvements that could benefit other users.

### Want to contribute?

1. Browse the existing styles and identify an improvement.
2. Test your changes on the target website.
3. Keep the CSS organized and avoid unrelated changes.
4. Open an issue to discuss a bug or proposed enhancement, or submit a pull request.
