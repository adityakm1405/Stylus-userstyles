## ✦ About the project

Websites have their own identity, but their default appearance doesn't have to be the final word.

**Stylus Userstyles** is my collection of website-specific CSS customizations, built to make everyday browsing feel more intentional. From immersive dark interfaces to cleaner gaming catalogues, each theme brings its own visual direction while preserving the underlying website.

- **Design-led** — carefully chosen palettes, layered surfaces, and consistent styling.
- **Lightweight** — CSS-based customization without rebuilding the original website.
- **Customizable** — explore the source, adjust the design, and make it your own.

## ⌘ Installation

### Recommended: Install with Stylus

[![Get Stylus](https://img.shields.io/badge/GET_STYLUS-Browser_Extension-164D36?style=for-the-badge&logo=firefoxbrowser&logoColor=white)](https://add0n.com/stylus.html)

**01 — Install the extension**

Install [Stylus](https://add0n.com/stylus.html) in the browser you use.

**02 — Choose a theme**

Open the [Themes directory](https://github.com/adityakm1405/Stylus-userstyles/tree/main) and navigate to the website theme you want.

**03 — Open the stylesheet**

Select the theme's `.user.css` file and click **Raw** in the upper-right area of GitHub's file viewer.

**04 — Install and enable**

Stylus should recognize the raw UserCSS file and display its installation interface. Review the style, install it, and enable it when visiting the target website.

<details>
<summary><strong>Having trouble installing a theme?</strong></summary>

- Make sure Stylus is installed and enabled in the same browser in which you opened the file.
- Open an individual `.user.css` file, not just a repository folder or the regular GitHub file view.
- If the installation screen does not appear, verify that you opened the raw stylesheet URL.

</details>

## ◇ Design principles

| Principle | Approach |
|:--|:--|
| **Color** | Intentional palettes with restrained accent colors |
| **Hierarchy** | Layered surfaces, balanced spacing, and clear visual structure |
| **Interaction** | Consistent hover states and useful visual feedback |
| **Consistency** | Cohesive styling across related components |
| **Maintainability** | Readable CSS and reusable design tokens where practical |

Every website has different requirements, so the implementation and visual direction vary from theme to theme.

## ⌘ Work with the source

Want to experiment, customize a theme, or contribute an improvement?

Clone the repository:

```bash
git clone https://github.com/adityakm1405/Stylus-userstyles.git
```

Open the relevant `.user.css` file in your preferred code editor and start exploring. You can adjust colors, spacing, typography, selectors, and other CSS properties to suit your preferences.

### Contributing

Contributions, bug reports, and thoughtful suggestions are welcome.

1. Explore the existing themes and identify an improvement.
2. Test your changes on the intended website.
3. Keep the CSS organized and focused on the relevant theme.
4. Open an issue or submit a pull request with a clear explanation of your changes.
